BIA CONTROL DE CONTENEDORES - PWA + SUPABASE
================================================

ENLACE OFICIAL
--------------
https://biahonduras.github.io/contenedores/index.html

Este paquete contiene la aplicación web progresiva completa y lista para
publicarse en GitHub Pages conservando exactamente sus carpetas.

ARCHIVOS PRINCIPALES
--------------------
- index.html: entrada de la aplicación.
- .nojekyll: permite que GitHub Pages publique correctamente la carpeta _next.
- _next/: archivos JavaScript y CSS compilados. No cambie su nombre ni estructura.
- manifest.webmanifest: configuración de instalación de la PWA.
- sw.js: servicio para instalación y funcionamiento sin conexión.
- pwa-icon-192.png y pwa-icon-512.png: iconos de la aplicación.
- brand/: logotipo y recursos de BIA Honduras.
- docs/Guia_Configuracion_Supabase_BIA.pdf: guía de configuración.
- supabase-setup.sql: tablas, permisos, almacenamiento y políticas de Supabase.

CONFIGURACIÓN DE SUPABASE
-------------------------
1. Abra su proyecto de Supabase y entre a SQL Editor.
2. Copie y ejecute todo el contenido de supabase-setup.sql.
3. En Authentication > URL Configuration configure:

   Site URL:
   https://biahonduras.github.io/contenedores/index.html

   Redirect URL:
   https://biahonduras.github.io/contenedores/**

4. Revise que Authentication esté habilitado y cree los usuarios que usarán
   la aplicación.
5. En Configuración dentro de la aplicación capture la URL de su proyecto y
   la clave pública anon o publishable. Nunca use service_role en el navegador.

PUBLICAR EN GITHUB PAGES
------------------------
1. Suba EL CONTENIDO de este paquete a la raíz del repositorio contenedores.
2. Conserve exactamente las carpetas _next, brand y docs.
3. No cambie la carpeta _next ni chunks. GitHub distingue cada nombre.
4. Confirme que .nojekyll esté en la raíz del repositorio.
5. En GitHub, abra Settings > Pages y publique desde la rama principal.

IMPORTANTE
----------
- La PWA necesita HTTPS para instalarse y registrar el service worker.
- El módulo de productos busca por codigo o codigo_barra en la tabla codigo y
  completa automáticamente la columna descripcion.
- El botón de copiar acceso y la confirmación por correo usan el enlace oficial.
